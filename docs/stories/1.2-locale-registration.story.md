# Story 1.2 — Registro formal do locale pt-br e aliases

## User Story

Como usuário brasileiro,
quero encontrar Português (Brasil) no seletor oficial de idiomas,
para selecionar e persistir o locale com o mesmo comportamento dos idiomas existentes.

## Acceptance Criteria

1. `Locale` reconhece `pt-br`.
2. `LOCALE_OPTIONS` e `LOCALE_META` exibem `Português (Brasil)` e `Portuguese (Brazil)`.
3. `pt-br`, `pt-BR`, `pt_BR` e `ptbr` normalizam para `pt-br`.
4. `localeConfigValue('pt-br')` retorna `pt-br`.
5. `display.language` salva `pt-br` preservando outras configurações.
6. O catálogo é registrado no `TRANSLATIONS` sem alterar contratos IPC ou backend.
