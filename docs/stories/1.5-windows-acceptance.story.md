# Story 1.5 — Aceitação do Desktop no Windows

## User Story

Como usuário do Hermes Desktop no Windows,
quero trocar para Português (Brasil) e continuar usando o Desktop,
para ter uma experiência traduzida sem perda de funcionalidade.

## Acceptance Criteria

1. É possível trocar de English para Português (Brasil) sem reiniciar.
2. A seleção persiste após reiniciar o Desktop.
3. Sessões, abas, Settings, Profiles, Connections, Files, Terminal, Preview e Review continuam utilizáveis.
4. Tema claro, tema escuro e escala maior não produzem truncamento impeditivo nos fluxos P0.
5. Labels de acessibilidade e estados de erro/carregamento permanecem compreensíveis.
6. É possível retornar para outro locale sem regressão.

## Tasks / Subtasks

- [ ] Produzir build/preview do Desktop conforme as capacidades disponíveis no Windows.
- [ ] Executar roteiro manual de aceitação no ambiente Windows.
- [ ] Registrar screenshots/logs apenas quando não expuserem dados sensíveis.
- [ ] Registrar problemas de layout, foco, acessibilidade ou terminologia.
- [ ] Corrigir problemas bloqueantes e repetir o roteiro.
