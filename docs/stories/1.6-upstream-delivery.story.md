# Story 1.6 — Preparação da entrega upstream local

## User Story

Como contribuinte do Hermes,
quero uma branch local limpa e um relatório completo da tradução,
para que a contribuição possa ser revisada antes de qualquer publicação remota.

## Acceptance Criteria

1. O diff final parte da `main` atual e contém somente o escopo Desktop/i18n/testes aprovado.
2. O status Git, diff, typecheck, lint e testes estão registrados.
3. A documentação referencia issue/PRs upstream relacionadas.
4. Nenhuma operação remota é realizada automaticamente.
5. A entrega inclui instruções claras para revisão e eventual criação manual da PR.

## Tasks / Subtasks

- [ ] Revisar status e diff da branch local.
- [ ] Executar `git diff --check` e auditoria de arquivos alterados.
- [ ] Confirmar ausência de segredos, dependências e alterações fora do escopo.
- [ ] Criar relatório local `docs/qa/final-delivery-1.6.md`.
- [ ] Preparar, mas não publicar, o texto sugerido da contribuição upstream.
