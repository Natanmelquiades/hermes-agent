# Story 1.3 — Catálogo completo pt-BR do Desktop

## User Story

Como usuário do Hermes Desktop no Brasil,
quero que a interface visível esteja em português brasileiro,
para usar sessões, configurações, conexões e panes com terminologia consistente.

## Acceptance Criteria

1. Existe `apps/desktop/src/i18n/pt-br.ts` alinhado ao `Translations` da `main` atual.
2. Todas as funções de interpolação preservam parâmetros e retorno.
3. Strings P0 do Desktop possuem tradução pt-BR revisada.
4. IDs, comandos, protocolos, nomes técnicos e dados operacionais permanecem inalterados.
5. O catálogo não contém dependências, scripts, telemetria, chamadas de rede ou leitura de segredos.
6. Textos herdados da PR #86292 são revisados e erros conhecidos não são propagados.

## Tasks / Subtasks

- [ ] Mapear todas as chaves presentes no `Translations` atual.
- [ ] Criar o catálogo completo usando os catálogos existentes como estrutura, não como cópia automática sem revisão.
- [ ] Traduzir primeiro as superfícies P0: seletor, shell, chat, configurações, conexões, arquivos, terminal, preview, review, erros e acessibilidade.
- [ ] Revisar termos segundo o glossário do PRD.
- [ ] Verificar placeholders, aspas, pontuação e pluralização.
- [ ] Auditar o diff para garantir que somente conteúdo de localização foi introduzido.
