# Story 1.4 — Testes de i18n, fallback e persistência

## User Story

Como mantenedor do Desktop,
quero testes que protejam o ciclo completo do locale pt-BR,
para evitar regressões quando o contrato de traduções evoluir.

## Acceptance Criteria

1. Aliases pt-BR normalizam corretamente.
2. O seletor persiste `display.language: pt-br` e preserva configurações não relacionadas.
3. Falha de gravação faz rollback do locale visível.
4. `document.lang` vira `pt-br` e `dir` permanece `ltr`.
5. Runtime resolve pt-BR, depois inglês e finalmente a chave.
6. Interpoladores recebem e devolvem os parâmetros corretos.
7. Plugin sem bundle pt-BR usa fallback em inglês.
8. Os testes não dependem de strings frágeis produzidas pelo locale do host quando a intenção é testar invariantes.
